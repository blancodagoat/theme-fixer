# theme-fixer

Discord's redesigned mobile app (the "visual refresh") renamed most of the semantic colors that Kettu, Bunny, Revenge and Vendetta themes set. `BACKGROUND_PRIMARY`, `TEXT_NORMAL`, `HEADER_PRIMARY` and friends are gone as of 345.0, so older themes only partly apply.

This page takes a spec 2 theme and adds the new names next to the old ones:

**https://blancodagoat.github.io/theme-fixer/**

Old names are kept, so the fixed theme still works on older Discord versions. Names the theme already sets are never overwritten. Everything runs in your browser.

## Where the mapping comes from

Discord 305.1 still shipped both naming schemes, so for most old names there's a new name with the exact same palette values in every theme. Those are the pairs marked exact. The rest are matched by closest value and role, and the page marks them as a guess.

The mapping lives in `map.json`. It's generated by `tools/build_map.py` from the hand-picked pairs in `tools/pairs.json`, and it reads the color tokens straight out of the Hermes bytecode of two decrypted IPAs:

```
pip install hermes-dec==0.1.7
python tools/build_map.py Discord_305.1.ipa Discord_345.0.ipa
```

When Discord ships another update, run it again with the new IPA. It warns about any target that no longer exists.
