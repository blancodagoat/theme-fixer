Theme fixer

Discord's redesigned mobile app renamed most of the colors that Kettu, Bunny and Vendetta themes set, so older themes only partly work. Load a theme and you'll get a copy that also sets the new names.

Rows marked guess had no exact match in Discord's own color data, so check those in the app.

    Changelog

    1.2

    September 16, 2026

    • Fixed: themes with "spec": "2" (text instead of a number) were refused with a confusing message. They're accepted now and saved with the number 2, which your mod needs before it will install them.
    • Fixed: a theme with "semanticColors": null showed a cryptic error instead of saying what was wrong.
    • Fixed: when a theme doesn't set CHAT_BACKGROUND, the chat background was taken from BACKGROUND_SECONDARY. It now uses BACKGROUND_PRIMARY, which is what older themes mean by it. Install links made from a theme link pick this up on their own. If you uploaded a file, load it again and get a new install link.
    • Added replacements for 11 more old color names, including the typing indicator, expression picker, faint borders, focus color, danger buttons, and the danger, idle and offline status colors.
    • Checked against 656 published themes.

    1.1

    September 16, 2026

    • Install links. Load a theme from a link and you get a link your mod can install directly. It fixes the original every time your mod loads it, so updates from the theme's author still come through.
    • Load a theme from a file and Get install link uploads the fixed copy and gives you a permanent link.

    1.0

    September 16, 2026

    • First version. Adds Discord's new color names next to the old ones in spec 2 themes, using the color data from Discord 305.1 and 345.0. Names without an exact match are marked as guesses.

    Color names come from Discord 345.0, compared against 305.1, the last version that had both the old and new names. Theme files stay in your browser unless you choose Get install link. Source on GitHub
